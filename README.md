# ✨ Quote Sanctuary

> Your thoughts deserve a universe.

Quote Sanctuary is a futuristic, cinematic personal quote web application where you can write, save, organize, design, and share your own thoughts, philosophies, motivational lines, and life quotes.

Built with a premium glassmorphism UI, glowing particle effects, aurora backgrounds, and immersive interactions.

---

## 🌌 Features

### ✍️ Quote Creator
- Write your personal quotes
- Optional author/name input
- Live quote preview
- Character counter
- Theme selector
- Beautiful typography styles

### 💾 JSON Storage
- Save quotes in structured JSON
- Auto-save using localStorage
- Export quotes as JSON
- Import quotes from JSON

### 🖼 Quote Gallery
- Responsive quote card gallery
- Search quotes instantly
- View saved personal thoughts
- Delete unwanted quotes

### 🎨 Wallpaper Generator
- Convert quotes into aesthetic wallpapers
- Download as PNG
- High-quality image export
- Perfect for sharing

### 🌠 Visual Experience
- Animated aurora gradients
- Floating glowing particles
- Glassmorphism UI
- Cinematic dark mode
- Smooth interactions
- Premium futuristic design

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/quote-sanctuary.git
```

Go to project folder:

```bash
cd quote-sanctuary
```

Run locally:

```bash
open index.html
```

Or simply use VS Code Live Server.
